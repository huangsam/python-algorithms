# Python Algorithms Agentic Docs

**Version:** 0.1.0
**Python Version:** >=3.11

This project provides a comprehensive collection of algorithm implementations in Python, organized by category. Each algorithm is implemented as a module that can be used as an "agent" for solving specific computational problems. The algorithms cover a wide range of topics including searching, sorting, dynamic programming, graph traversal, and more, making this a valuable resource for learning and applying algorithmic techniques in Python.
